# 2048 Specification

## Overview
*   **Genre**: Number Puzzle
*   **Aesthetic**: Vibrant Gradients / Neumorphism
*   **Engine**: Vanilla JS / CSS Transform APIs

## Core Mechanics
1. **Grid Matrix Engine**: Abstract 4x4 coordinate processing layer handling merge logic and directional swiping arrays.
2. **Animation Engine**: Tiles operate on separate DOM elements decoupled from the logical grid architecture. This leverages hardware-accelerated CSS `transform: translate()` for frictionless slide effects and `scale()` for overlapping merge visual interactions without triggering layout reflows.
3. **Merge Logic**: Parses movement vectors algorithmically to determine maximum furthest available tile limits and sequential merge prioritization based on user displacement.
4. **End**: The game is over when the board is full and no neighbours match. Reaching 2048 shows a win screen with "Keep going"; the game then continues until it is over.

## Controls
Arrow keys / `WASD` move · swipe on touch screens · `T` next theme. Keys and swipes are ignored while the records panel or theme menu is open.

## Themes
The palette button in the header opens a menu: 原版 (original, default: beige board, warm gradient tiles, Outfit), 深色 (dark), 淺色 (light), 新粗獷 (neubrutalism: lavender page, thick black outlines, hard offset shadows, flat saturated tiles, Archivo Black numerals). The choice is saved in localStorage (`lgt:2048:theme`). Tile colours in the three new themes come from one ramp of custom properties per theme (`--t2` … `--t2048`, `--tsuper`, plus `-f` text and `-s` shadow overrides), so every value stays distinct and readable.

## Records
The trophy button opens the records panel (best score plus the last 10 games, stored only in this browser under `lgt:2048:records`). A game is recorded once, when it is over (no moves left), with the score and the largest tile (`最大方塊 512`); abandoning a game with New Game, or restarting from the win screen, records nothing. The BEST box shows the recorded best (or the current score if it is higher); the game-over screen shows 新紀錄！ or the best. A best saved by the old version (`2048-best-score`) seeds the table once.
