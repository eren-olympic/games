# Zen Hitori Completed!

The Hitori game implementation is now fully complete! Enjoy a tranquil but challenging logic puzzle experience featuring our "Zen Glassmorphism" aesthetic.

## Features Delivered
- **Infinite Puzzles**: The game features a custom, robust generator that creates dynamically solvable puzzles on-demand with varying difficulties (5x5, 6x6, and 8x8 grids).
- **Core Rules Validation**: Full validation logic checking Adjacency, Connectivity, and Unique Numbers guarantees the accuracy of puzzle checking.
- **Mouse Interactions**: Intuitive left-clicks to shade out a duplicate and right-clicks to lock in a safe number.
- **Premium Aesthetics**: Serene colors, gently floating abstract background orbs, satisfying CSS element bounces, and smooth context-sensitive marking.

## How to Play
A local HTTP server has been started on a new port.
**Open your browser to**: [http://localhost:8081](http://localhost:8081)

1. Select your desired grid size and click **New Game**.
2. **Left Click** a cell to shade it (black it out).
3. **Right Click** a cell to circle it (mark it as definitely unshaded/safe).
4. **Click Check** at the bottom anytime you think you've solved it (or want to see where the errors are!).
5. **Click Rules** if you need a reminder of how to play Hitori.
